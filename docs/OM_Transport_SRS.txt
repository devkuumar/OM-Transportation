## 4. Functional Requirements

### FR-01 Navigation
Users shall be able to navigate:
Home
About
Services
Vehicles
Transport Quote
Locations
Partner With Us
Contact

### FR-02 Vehicle Filtering
If the fleet grows, users should be able to filter by:
- Length
- Vehicle type
- Availability

### FR-03 Quote Form
The form shall:
- Validate required fields
- Reject invalid phone/email where applicable
- Sanitize input
- Prevent duplicate/spam submissions where possible
- Show success/failure state

### FR-04 WhatsApp
Generate a pre-filled WhatsApp message using the submitted enquiry.

### FR-05 Phone
Use tel links for both business numbers.

### FR-06 Maps
Open the supplied Google Maps destination.

### FR-07 Partner Form
Accept vehicle-owner enquiries.

### FR-08 Responsive UI
All functionality shall work on mobile, tablet and desktop.

## 5. Validation Requirements

Required for transport request:
- Name
- Phone
- Pickup
- Delivery
- Vehicle/load requirement

Phone:
- Validate Indian phone format reasonably.
- Do not block legitimate users unnecessarily.

Email:
- Optional unless client later requires it.

Dimensions/weight:
- Accept text or numeric values depending on UI.

## 6. Security Requirements

The system shall:
- Validate input server-side
- Sanitize user content
- Rate-limit public forms
- Protect API routes
- Keep credentials in environment variables
- Never expose database/service keys
- Use secure database policies
- Avoid logging unnecessary personal information

## 7. SEO Requirements

Implement:
- Unique title
- Meta description
- Open Graph
- Canonical URL
- Sitemap
- Robots.txt
- Structured data
- LocalBusiness schema
- Descriptive image alt text

## 8. Accessibility Requirements

- WCAG-conscious contrast
- Keyboard navigation
- Labels for inputs
- Visible focus
- Semantic headings
- Alt text
- Accessible error messages
- Adequate touch targets

## 9. Performance Requirements

Target:
- Optimized images
- WebP/AVIF
- Lazy loading
- Minimal JavaScript
- Code splitting
- Font optimization
- Caching
- Fast mobile loading

## 10. Error Handling

Provide user-friendly states for:
- Invalid form
- Network error
- Server error
- Submission failure
- No vehicle availability
- Missing image
- Map failure

Never expose stack traces or internal errors to users.

## 11. Analytics Events

Track:
- call_click
- whatsapp_click
- request_vehicle_click
- quote_submit
- partner_submit
- directions_click
- contact_submit
- vehicle_view

Do not collect unnecessary sensitive information.

## 12. Database Security

If Supabase/PostgreSQL is used:
- Apply least-privilege access
- Protect public insert endpoints
- Restrict admin operations
- Use server-side privileged keys only
- Apply validation before persistence

Only verified business information may be presented as factual.

- Capacity

- Reviews

- Certifications
- Branches
- Routes
- Revenue
- Customer counts

Vehicle length categories 14/17/19/20/22 ft and Tata Ace may be shown because they appear in the supplied business materials.

Exact technical specifications require client confirmation.

## 15. Deployment Requirements

Prepare for production deployment using a modern hosting platform such as Vercel or equivalent.

Environment variables should include only required secrets/configuration, for example:
DATABASE_URL
SUPABASE_URL
SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY
MAPS_KEY
EMAIL_PROVIDER_KEY

Never commit secrets.
